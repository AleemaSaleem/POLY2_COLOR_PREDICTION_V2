# POLY-2 Baseline C Streamlit Colour Predictor

## What this app does

This Streamlit application loads the saved POLY-2 Baseline C CatBoost models and predicts:

- Lab **L**
- Lab **a**
- Lab **b**

from an Excel file containing the model-ready process features.

The app **does not retrain** the models.

## Baseline C scope

The deployed models are the Baseline C models:

1. 202-F0 excluded
2. TPD <= 0 causal shutdown/non-production trajectories excluded
3. Throughput regime / transition features representing the approximately 400 → 600–800 TPD operating shift
4. No previous Lab colour values used as predictors

## Folder structure

Place the saved model package next to `app.py`:

```text
poly2_baseline_c_streamlit/
│
├── app.py
├── requirements.txt
├── README.md
│
└── poly2_baseline_c_models_v4/
    ├── catboost_L_BaselineC.cbm
    ├── catboost_A_BaselineC.cbm
    ├── catboost_B_BaselineC.cbm
    └── baseline_c_selected_features.json
```

The app only needs the `.cbm` model files and `baseline_c_selected_features.json` for prediction.

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

The browser will open the Streamlit application.

## Input Excel

The app includes a **Download Excel Input Template** button.

Use that template to create the input workbook.

Each row represents one prediction sample.

The required columns are exactly the feature columns used by the saved Baseline C models.

### Important

Do not rename feature columns.

Do not add previous Lab L/a/b values as predictors.

Do not use future information relative to the prediction/sample timestamp.

## Output

The application displays:

- Predicted L
- Predicted a
- Predicted b
- prediction-region description

and provides:

`POLY2_Baseline_C_Predictions.xlsx`

for download.

If the uploaded Excel also contains `LAB_L`, `LAB_A`, and `LAB_B`, the application additionally displays the actual Lab values and prediction errors.

## Model files

The model files are not embedded in this source package because they are the trained weights generated by the user's Baseline C notebook.

Copy your existing:

```text
poly2_baseline_c_models_v4
```

folder into this project directory before running the app.
